Organização

Informe o login da organização (o nome que aparece em github.com/<org>). Deixe "Repositório" em branco para somar as PRs abertas de todos os repositórios da organização, ou preencha para ver apenas as de um repositório específico (ex.: cli para github.com/cli/cli).

Avançado

No Windows, se informar um caminho completo, inclua a extensão .exe.

Caminho do gh e refresh são globais (valem para todas as actions); organização e repositório são desta tecla.
