Repositório

Mostra as PRs abertas do repositório informado (de qualquer autor, não só as suas). Deixe "Organização" em branco para usar seu próprio usuário como dono do repositório (ex.: github.com/<seu-usuário>/<repo>), ou preencha com o login de uma organização (ex.: github para github.com/github/cli).

Avançado

No Windows, se informar um caminho completo, inclua a extensão .exe.

Caminho do gh e refresh são globais (valem para todas as actions); organização e repositório são desta tecla.
