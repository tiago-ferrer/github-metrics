Deixe "Organização" em branco para contar em toda a sua conta GitHub. Preencha com o login de uma organização (ex.: github) para restringir esta tecla só ao que você fez dentro dela.

Importante: essa métrica vem da API de eventos do GitHub, que só cobre os últimos ~90 dias (e no máximo ~300 eventos). "Último ano" aqui reflete só o que a API tiver disponível, não um ano de verdade — se você não tem atividade recente, pode mostrar 0 mesmo tendo feito isso há mais tempo.
